Piezo Buzzer Wiring Schematic

Wiring guide for Arduino Uno/Nano & Witpro (ESP8266)

1. Arduino Uno / Nano Wiring: 
[ Arduino Pin D8 ] --------(+) [ Piezo Buzzer ] (-)-------- [ 100-220Ω Resistor ] -------- [ GND ]
2. Witpro / ESP8266 (NodeMCU) Wiring: 
[ Witpro Pin D1 / GPIO 5 ] -(+) [ Piezo Buzzer ] (-)-------- [ 220-330Ω Resistor ] -------- [ GND ]

Important Hardware Rule: Always use a Passive Buzzer for melody playback. Active buzzers have an internal oscillator and can only produce one continuous beep.
